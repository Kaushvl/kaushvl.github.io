// case study · 2023

Employee churn predictor

A tabular model that scores attrition risk per employee so HR teams can act before someone quietly checks out.

Role
Personal project
Year
2023
Status
Open source
Stack

Repo

Classic supervised problem — predict whether an employee leaves in the next N months from tenure, role, comp, manager and engagement features. Most of the work was feature engineering and dealing with leakage; a few seemingly innocent fields were essentially the label in disguise.

XGBoost landed at 87.3% test accuracy, with a precision/recall trade-off tuned for HR's actual use case (false positives are cheap, false negatives miss the people you cared about). A small Flask app wraps the model with a per-employee risk view and the top three contributing features per prediction.
