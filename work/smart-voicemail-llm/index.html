// case study · 2024

Smart voicemail
with LLM

A weekend project that turned into something I actually use — transcribes a voicemail, classifies what it's about, and surfaces the action items so I don't have to listen.

Role
Personal project
Year
2024
Status
Open source
Stack
Python · Whisper · OpenAI
Repo
github.com/Kaushvl/SmartVoiceMailUsingLLM ↗

The setup is simple: Whisper transcribes the audio, an LLM does a structured pass to extract category, urgency, sender intent and a one-line summary, and the result lands in a small inbox view. The interesting bit was the prompt — a short JSON-schema-style template that hallucinated badly until I added two in-context examples of edge cases (silent messages, multilingual snippets).

Mostly a reminder to myself that the unsexy 30 lines of prompt and post-processing usually do more work than the model choice.
