// case study · 2023

Voice-first
productivity assistant

A small CLI/voice assistant that turns spoken commands into tasks, calendar events and quick lookups — built to scratch my own itch.

Role
Personal project
Year
2023
Status
Open source
Stack
Python · OpenAI · SpeechRecognition · FastAPI · PostgreSQL
Repo
github.com/Kaushvl/AIBasedTodoAssistant ↗

Speech goes in via the local mic, an intent classifier figures out what kind of command it is, and the right handler runs — usually a single small function with a tight prompt. Everything persists to a tiny FastAPI + Postgres backend so the same tasks show up across devices.

The interesting failure mode was the obvious one: a model that's a little too willing to interpret ambient noise as a command. The fix wasn't smarter — it was adding a confidence floor and an "I didn't catch that, try again" affordance. Worth remembering: knowing when not to act is half of acting well.
